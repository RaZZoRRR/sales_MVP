# Sales MVP

Мобильный одностраничный MVP для GitHub Pages.

Изменения v2:
- каждая продажа хранится как отдельная операция в локальном demo-режиме;
- для каждого продукта в отчёте показываются количество и суммарное УП;
- ЗЛС показывает каждую продажу с её суммой и общий УП;
- нулевые продукты не попадают в итоговый отчёт;
- ЗП и Детская пока не автоматизируются;
- все цены — условные единицы.
