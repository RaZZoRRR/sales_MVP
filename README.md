# Sales MVP v3

Пока без Supabase. Справочник продуктов и продажи сохраняются в localStorage.

Добавлено: форма настроек для добавления и редактирования продуктов; категория, полное название, название в отчёте, цена в УП и правило расчёта. Продажи хранятся отдельными операциями. Отчёт показывает только продажи > 0 и суммарное УП по продукту. ЗЛС сохраняет сумму каждой продажи. ЗП и Детская пока не автоматизируются.
