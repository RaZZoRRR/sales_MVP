# MVP учёта продаж

Простой мобильный одностраничник для GitHub Pages + Supabase.

## Что уже заложено

- локальный demo-режим без Supabase;
- группы ЮЛ, Сим, ОПС и др.;
- отчёт показывает только позиции с количеством > 0;
- УП считается автоматически для фиксированных продуктов;
- ЗЛС рассчитывается по введённой сумме;
- СберЗдоровье + опции 1100/2200;
- ручные разделы ЗП и Детская пока не автоматизируются;
- PWA manifest для добавления на главный экран.

## Запуск с Supabase

1. Создать проект Supabase.
2. Выполнить `supabase.sql` в SQL Editor.
3. В `app.js` указать `SUPABASE_URL` и publishable/anon key.
4. Загрузить файлы в GitHub repository.
5. Включить GitHub Pages для ветки/папки с сайтом.

## Важно

Цена СберПраво отсутствует в предоставленном справочнике, поэтому в MVP она намеренно заблокирована до уточнения.

ЗЛС:
- 1–999 ₽: 0,08
- 1000–2999 ₽: 0,25
- 3000–3999 ₽: 0,35
- далее +0,10 за каждую полную следующую 1000 ₽.

Все цены — условные единицы.
